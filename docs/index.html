Capabilities

Why AIRIS-CLI?

Built from the ground up for developers who need an intelligent, responsive terminal that adapts to their workflow.

⚡

AI-Powered

Natural language understanding lets you ask questions, generate code, and automate tasks without leaving the terminal.

♻

Context-Aware

Remembers your project structure, preferences, and history to provide relevant, targeted assistance every time.

⚛

Plugin System

Extend functionality with a rich plugin ecosystem. Write your own plugins in Python, JavaScript, or any language.

🔒

Secure by Design

Sandboxed execution, permission controls, and audit logging ensure you stay in control of what runs in your shell.

⚙

Fully Configurable

Theme engine, custom keybindings, aliases, and profiles. Make AIRIS-CLI behave exactly the way you want.

⚡

Blazing Fast

Written in Rust with a focus on performance. Sub-millisecond startup and minimal memory footprint.

Commands

Terminal-First Experience

Designed for keyboard natives. Every command is intuitive, discoverable, and documented.

airis init Initialize AIRIS environment in current directory setup
airis ask Ask a question or request a task in natural language ai
airis code Generate, review, or refactor code with AI assistance ai
airis plugin Manage plugins: install, list, remove, and configure system
airis config View and modify configuration settings system
airis doctor Diagnose and repair AIRIS-CLI installation utility
Get Started

Install in Seconds

One command. Zero dependencies. Works on Linux, macOS, and Windows.

bash
# Install AIRIS-CLI globally $ npm install -g airis-cli # Or install via cargo (Rust) $ cargo install airis-cli # Verify installation $ airis --version

Requires Node.js 18+ or Rust 1.70+. See the installation guide for details.
